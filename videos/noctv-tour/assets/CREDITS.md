# Media provenance

- Application recordings: NOCtv community demo, recorded locally by `scripts/capture.mjs`. All inventory, addresses and incidents are synthetic. No company service is contacted.
- NOCtv mark: `web/icon.svg` from this repository.
- Map geometry and vendor marks visible inside the application retain the credits documented in the repository's maps/brands documentation.
- GSAP 3.14.2: https://cdn.jsdelivr.net/npm/gsap@3.14.2/dist/gsap.min.js — original copyright and license header preserved. See https://gsap.com/standard-license.
- Soft click: HyperFrames bundled `click-soft.mp3`, sourced from Pixabay under the Pixabay Content License (https://pixabay.com/service/license-summary/). Incorporated in the rendered tour; the standalone sound is not redistributed in this repository. Recreate it with the media-use command in the video README.
- Title reveal: adapted from HyperFrames registry `blur-in` timeline recipe (https://github.com/heygen-com/hyperframes). Only the short reveal recipe is used; the application visuals are recordings, not registry mockups.

There is no music or voiceover. On-screen explanations are available in English and Portuguese; the recorded application UI remains English.
