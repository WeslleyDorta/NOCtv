# Considered storylines

Selected: **Follow an incident** — a real cursor goes from the geographic map into a switch port, sees a simulated failure and recovery, then visits the remaining screens. Opens on an already moving map. Real application colors, local click sounds, no voiceover. Matches the requested demonstration.

Alternative: **Install to first signal** — terminal commands, demo, local source configuration and first collected device. Not selected: no real external source is authorized for this public recording.

Alternative: **One wall, nine views** — an uninterrupted TV rotation. Not selected: it would show less of the interactive port and service diagnostics.
